# Intro Bumper

This folder should contain `intro_bumper.mp4` — a short (3–5 second) cinematic
bumper shown before each episode. The file is intentionally not committed to
keep the repository lightweight.

The video should follow the brand palette:
- Black `#0A0A0A` background
- Blood Red `#C8102E` accent
- White `#FFFFFF` "ADWA SHORT" logotype fading in/out

Place the file at `assets/images/intro_bumper.mp4` before building the release
APK / IPA. If absent, the player will simply skip the intro and play the
episode directly.
